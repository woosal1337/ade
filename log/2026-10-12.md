# 2026-10-12: Git profile sources and trust

## Done

1. Profile sources: a local folder, `owner/repo[/subfolder][@ref]` on GitHub, or a Git URL with `//subfolder` and `#ref`. plan, apply, status, doctor, list, export, pack, use, and remote take a source.
2. Trust: a risk summary, a trust prompt before the first apply of a Git source, and a new prompt when the summary changes. Before trust, ade does not resolve secrets.
3. `ade use`, `ade trust`, and `ade pack`. Pack refuses token values and writes a README.
4. `examples/starter`: a small published profile.

## Found and fixed

- Git sets `GIT_INDEX_FILE` for a hook. ade passed it to its own Git calls, so a skill checkout wrote into a foreign index. ade now removes the repository variables of Git before each call.
- Biome formatted the generated `ade.schema.json` in `examples/` differently from ade. Biome now skips the files that ade writes there.
- After a trust prompt, the source line still said "not trusted". The apply now reads the trust state again.
