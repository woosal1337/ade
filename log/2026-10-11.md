# 2026-10-11: Version 0.1.0 foundation and engine

Task: TD-209 in the Elliptic Todo board.

## Done

1. Created the private GitHub repository `woosal1337/ade` with the shared repository foundation. The repository has no commits.
2. Researched the stack and the harness formats. TypeScript 7 has no stable parser API, so the comment check uses the TypeScript 6.0.3 API under the alias `typescript-api`.
3. Built the engine: profile schema, five harness adapters, secret references, Git and link skills, plan, apply with backups and rollback, revert, status, capture, doctor, and bundles.
4. Built the CLI with 18 commands and JSON output, and the SDK exports in `src/index.ts`.
5. Added 45 tests in 13 suites. All pass on Node.js 24.13.0 on macOS.
6. Installed both Git hooks. A comment probe blocked the commit hook.

## Found and fixed during the acceptance check

- A shared skill can be a link to a development checkout. Capture made a copy, so the plan wanted to replace the link. The `link` skill source keeps such a skill as a link.
- Revert left the empty folders and the empty `mcpServers` object that apply created. Apply records now list them, and revert removes them when they are empty.
- Two records in the same second sorted by their random suffix. Record ids now have milliseconds, and each new id sorts after the last one.
- `localeCompare` gave a locale-dependent file order. A byte-order compare replaced it.
