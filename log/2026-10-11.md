## Found and fixed during the acceptance check

- A shared skill can be a link to a development checkout. Capture made a copy, so the plan wanted to replace the link. The `link` skill source keeps such a skill as a link.
- Revert left the empty folders and the empty `mcpServers` object that apply created. Apply records now list them, and revert removes them when they are empty.
- Two records in the same second sorted by their random suffix. Record ids now have milliseconds, and each new id sorts after the last one.
- `localeCompare` gave a locale-dependent file order. A byte-order compare replaced it.
