# starter

A small public ade profile: global rules, one skill, and one documentation MCP server.

## Use it

1. Show the changes for your machine:

   ```bash
   ade plan woosal1337/ade/examples/starter
   ```

2. Apply the profile. ade shows what it runs and writes, and asks you to trust the source:

   ```bash
   ade apply woosal1337/ade/examples/starter
   ```
